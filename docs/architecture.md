# Architecture

## Overview

The VRM21 Discrete Wavelet Transform implementation provides a hardware-oriented Level-1 Discrete Wavelet Transform (DWT) and Inverse Discrete Wavelet Transform (IDWT) architecture.

The design is implemented as a pair of streaming processing modules:

* `vrm_dwt_axi.v` — Level-1 forward DWT.
* `vrm_idwt_axi.v` — Level-1 inverse DWT.

Both modules use AXI4-Lite for coefficient configuration and AXI4-Stream for sample transport.

The filter-bank processing is provided by the Quadrature Mirror Filter (QMF) implementation from the external RTL dependency.

## Forward DWT Architecture

The forward transform accepts a 32-bit stereo sample stream:

```text
{Right[15:0], Left[15:0]}
```

Each stereo channel is processed independently by a QMF analysis filter bank.

The processing flow is:

```text
AXI4-Stream Input
       │
       ▼
Stereo Sample Split
       │
       ├───────────────┐
       ▼               ▼
QMF Analysis Core   QMF Analysis Core
Left Channel        Right Channel
       │               │
       ▼               ▼
Low / High         Low / High
Subbands           Subbands
       │               │
       └───────┬───────┘
               ▼
        64-bit Packing
               │
               ▼
        AXI-Stream Decimator
               │
               ▼
        AXI4-Stream Output
```

The output sample format is:

```text
{High_R, High_L, Low_R, Low_L}
```

Each component occupies 16 bits, producing a total output width of 64 bits.

The decimator retains one sample for every pair of input samples, reducing the output sample rate by a factor of two.

## Inverse DWT Architecture

The inverse transform accepts the 64-bit subband format generated by the forward DWT:

```text
{High_R, High_L, Low_R, Low_L}
```

The processing flow is:

```text
AXI4-Stream Input
       │
       ▼
      64-bit
    Interpolator
       │
       ▼
Zero-Insertion
       │
       ▼
Subband Extraction
       │
       ├───────────────┐
       ▼               ▼
QMF Synthesis Core  QMF Synthesis Core
Left Channel        Right Channel
       │               │
       ▼               ▼
Reconstructed      Reconstructed
Left Channel       Right Channel
       │               │
       └───────┬───────┘
               ▼
        32-bit Packing
               │
               ▼
        AXI4-Stream Output
```

The reconstructed stereo output format is:

```text
{Right[15:0], Left[15:0]}
```

The interpolator increases the sample rate by inserting a zero-valued sample after each received subband sample.

## Coefficient Configuration

Both transform modules contain an internal coefficient register bank.

The coefficient bank is configured through AXI4-Lite and is flattened into a packed vector before being connected to the QMF processing cores.

The default configuration uses:

```text
DATAW     = 16
COEFW     = 16
NTAPS     = 8
ACCW      = 64
OUT_SHIFT = 15
```

The default eight-tap configuration is intended to support the Symlet 4 (`sym4`) coefficient set used by the provided simulation workflow.

## External RTL Dependencies

The top-level DWT and IDWT modules do not independently implement the complete analysis and synthesis filters.

The following modules are provided by the external QMF dependency:

```text
qmf_analysis_core
qmf_synthesis_core
```

These modules are required during simulation and synthesis.

The QMF implementation is available from the VRM21 Studios Quadrature Mirror Filter repository.

The FIR processing architecture used by the QMF implementation also originates from the corresponding FIR module dependency.

For dependency details, see `rtl/README.md`.

## Design Scope

The current RTL implementation provides a Level-1 transform only.

It does not internally implement recursive multilevel decomposition.

A higher-level multilevel architecture can be constructed by connecting the low-frequency output of one DWT level to another DWT stage.

Conceptually:

```text
Input Signal
     │
     ▼
  DWT Level 1
     │
     ├── High-Frequency Detail
     │
     └── Low-Frequency Approximation
                 │
                 ▼
             DWT Level 2
                 │
                 ├── Detail
                 │
                 └── Approximation
```

The same principle can be applied in reverse when constructing a multilevel IDWT system.
